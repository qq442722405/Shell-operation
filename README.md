# APP窗口容器 · 自定义预设版

适用于 6480×960 超长车机屏幕。

## 功能

- 自定义顶部安全空白
- 自定义底部安全空白
- 不再固定左/中/右
- 自定义窗口 X / Y
- 自定义窗口宽度 / 高度
- 自定义 DPI 参数
- 给窗口预设命名
- 保存预设
- 编辑/删除预设
- 添加已安装 APP
- 先选 APP，再点预设启动
- APP 快捷方式本地保存
- 预设本地保存
- 保留已测试成功的 ActivityOptions.setLaunchBounds()

## 示例

顶部空白 40
底部空白 60

预设“导航”：

X=0
Y=40
宽=2032
高=860
DPI=240

先点击高德地图，再点击“导航”，就按该 Bounds 启动。

## DPI说明

当前版本会保存 DPI 参数并显示在预设中，但普通第三方 APP 不能仅靠 setLaunchBounds 强制改变系统 Display DPI。

因此本版本不会虚假声称 DPI 已经被系统修改。

如果测试发现车机需要真正修改 APP 窗口密度，下一步可以针对车机系统接口继续做。

## 打包
